# Save Walter White — fan recreation

A deliberately retro homage to Walter Jr.'s fundraiser website from **Breaking Bad**, inspired by the reference at https://save-walt.onrender.com/.

## Deployment
Static HTML/CSS/JS, no dependencies or build step. Configure Vercel with Framework Preset **Other** and Root Directory `.` (repository root).

## Behavior
The supporter form is a **demo only**. It validates the name/email fields, updates a browser-local counter, and shows a thank-you message. It never sends or saves personal details, has no shared database, and **does not accept payments**.

## Imagery
Photos and the classic banner/button are referenced from the public `matiasroj0/save-walter-white` GitHub project and were originally from the series. All copyrights remain with their owners. This is a noncommercial fan recreation, not an official AMC site.

## Files
- `index.html` — content and semantic structure
- `style.css` — visual styling/responsive layout
- `script.js` — local signup demo
